The CLI is the `bin` of the `shadcn-bootstrap` npm package, so `npx` runs it with no install. It has no runtime dependencies and needs Node 18+. It downloads registry files from jsDelivr at the version pinned in `components.json`, so your CSS and the CLI stay in step.

> The CLI ships in **{RELEASE_VERSION}**. Every terminal on this page is marked *planned* and shows the designed output.

## init

Detects your framework, writes `components.json`, copies `tokens.css`, `bridge.css` and an empty `components/index.css`, creates `lib/utils.ts` (the `cn` helper the React and Vue components use), and prints where to import the CSS. It never edits your existing source files.

| Detected by | Framework | Components go to | CSS goes to | Prints imports for |
| --- | --- | --- | --- | --- |
| `next.config.*` | Next.js | `components/ui/*.tsx` | `styles/` | `app/layout.tsx` |
| `vite.config.*` + `react` | React (Vite) | `src/components/ui/*.tsx` | `src/styles/` | `src/main.tsx` |
| `vite.config.*` + `vue`, or `nuxt.config.*` | Vue / Nuxt | `src/components/ui/<name>/*.vue` | `src/styles/` / `assets/css/` | `src/main.ts` / `nuxt.config.ts` |
| `angular.json` | Angular | `src/app/ui/*.ts` | `src/styles/` | `angular.json` `styles` |
| none of these | Plain HTML | none (classes only) | `css/` | `<link>` tags with SRI |

## add

Resolves dependencies and copies each component: its CSS, plus the component source for your framework (`components/ui/checkbox.tsx`, `components/ui/checkbox/Checkbox.vue` or `src/app/ui/checkbox.ts`). It adds an `@import` for the CSS to `components/index.css`, records a hash of every file, and refuses to overwrite a file you've edited unless you pass `--overwrite`.

## Custom registries

Point `registry` in `components.json` at your own URL to serve your team's components, the same way shadcn registries work. The format is the JSON Schema at `dist/registry/schema.json`.
