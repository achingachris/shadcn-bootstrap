> shadcn-bootstrap isn't on npm yet. Snippets use the first release, **{RELEASE_VERSION}**; until it's published, every preview on this page uses the local build in place of the CDN file.

Using a framework? Follow its guide instead: [Next.js](/docs/frameworks/next/), [React](/docs/frameworks/react/), [Vue](/docs/frameworks/vue/) or [Angular](/docs/frameworks/angular/). They cover the CLI, the components, CSS imports, loading Bootstrap's JavaScript on the client, and dark mode. This page covers plain HTML projects and the parts every setup shares.

## Requirements

- Bootstrap **6** (currently `{bootstrap.version}`). Bootstrap 5 isn't supported.
- Browsers: the same floor as Bootstrap 6. Chrome and Edge 130+, Firefox 132+, Safari 18+.

## CDN

Add Bootstrap's CSS first, then shadcn-bootstrap. Bootstrap 6's JavaScript is ESM-only, so its script tag needs `type="module"`.

export const cdnPage = `<!doctype html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <link rel="stylesheet" href="${bootstrap.css.href}"
        integrity="${bootstrap.css.integrity}" crossorigin="anonymous">
  <link rel="stylesheet" href="${shadcnBootstrapCdn()}">
</head>
<body>
  <div class="d-flex gap-2">
    <button class="btn btn-solid theme-primary">Get started</button>
    <button class="btn btn-outline">Learn more</button>
  </div>
  <script type="module" src="${bootstrap.js.src}"
          integrity="${bootstrap.js.integrity}" crossorigin="anonymous"></script>
</body>
</html>`;

<Example code={cdnPage} document title="index.html" minHeight="8rem" />

The bundle contains tokens, bridge and every built component. Integrity hashes for shadcn-bootstrap will be published with each release.

## CLI

The CLI copies files into your project instead of linking a bundle, so you can edit them: CSS for every project, plus React, Vue or Angular components in framework projects. It's the shadcn workflow, and it arrives in {RELEASE_VERSION}. In a plain HTML project it looks like this:

<Terminal
  command="npx shadcn-bootstrap init"
  output={snippet1}
  planned
/>

<Terminal command="npx shadcn-bootstrap add button card input" output={addOutput(["button", "card", "input"], "html")} planned />

See [CLI](/docs/cli/) for every command.
