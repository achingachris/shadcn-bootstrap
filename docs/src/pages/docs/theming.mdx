shadcn-bootstrap uses shadcn's token names. Components read them directly, and the bridge maps them onto Bootstrap 6's `--bs-*` variables, so Bootstrap components you haven't added CSS for follow too.

## Tokens

Defaults below are the **zinc** base color. "Now" shows the value in the mode you're viewing.

<TokenTable />

Each pair of `background`-style tokens has a matching `-foreground` for text on top of it: `--primary` with `--primary-foreground`, `--card` with `--card-foreground`, and so on.

## Change a token

Override tokens after shadcn-bootstrap loads. Every component reads them, so one change restyles everything.

export const demo = `<div class="d-grid gap-3" style="width: 20rem">
  <div class="d-flex gap-2">
    <button class="btn btn-solid theme-primary">Primary</button>
    <button class="btn btn-outline">Outline</button>
  </div>
  <input class="form-control" placeholder="Focus me to see the ring">
  <div class="d-flex align-items-center gap-2">
    <div class="switch"><input type="checkbox" role="switch" id="t1" checked></div>
    <label for="t1">Notifications</label>
    <span class="badge ms-auto">New</span>
  </div>
</div>`;

## Base colors

Five base colors ship as theme files: **zinc** (default), **slate**, **stone**, **neutral** and **gray**. Each file only sets token values, so load it after the bundle.

<Example
  title="Slate"
  code={`<link rel="stylesheet" href="${shadcnBootstrapCdn("dist/css/themes/slate.css")}">\n\n${demo}`}
  preview={demo}

For accent colors and radius, use the [theme generator](/themes/). It outputs a block like the one above.

Put tokens on an element with a `data-sb-theme` attribute. The bridge re-applies inside it, so Bootstrap's variables pick up the new values for that subtree only.
