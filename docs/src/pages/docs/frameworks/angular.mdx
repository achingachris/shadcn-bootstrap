The CLI copies standalone components and directives into `src/app/ui/`. Following Angular conventions (and spartan/ui, the Angular shadcn port), native elements get a directive, `<button sbButton variant="outline">` and `<input sbInput>`, so forms and accessibility work as usual. Composite parts are elements: `<sb-card>`, `<sb-card-header>`, `<sb-switch>`. Everything renders Bootstrap 6 classes, styled by shadcn-bootstrap's CSS.

## Load Bootstrap's JavaScript

Bootstrap 6's JavaScript is ESM and reads `document`. Import it in `afterNextRender`, which only runs in the browser, so it also works with server-side rendering. It listens on `document`, so `data-bs-*` attributes then work in every template.
