The CLI copies single-file components into `src/components/ui/<name>/` and you use them like shadcn-vue: `<Button variant="outline">`, `<Card>`, `v-model` on `<Input>`, `<Checkbox>` and `<Switch>`. They render Bootstrap 6 classes, styled by shadcn-bootstrap's CSS.

## Install

<Terminal command={installCommand} output={installOutput} />

<Terminal command="npx shadcn-bootstrap init" output={vue.init} planned />

The components import from `@/`, so add the alias to `vite.config.ts` and `tsconfig.json` if your template doesn't have it.
