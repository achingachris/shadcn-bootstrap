The CLI copies components into `src/components/ui/` and you use them like shadcn/ui: `<Button variant="outline">`, `<Card>`, `<CardHeader>`. They render Bootstrap 6 classes, styled by shadcn-bootstrap's CSS. This guide uses Vite; for server rendering, see [Next.js](/docs/frameworks/next/).

## Install

<Terminal command={installCommand} output={installOutput} />

<Terminal command="npx shadcn-bootstrap init" output={react.init} planned />

The components import from `@/`, so add the alias to `vite.config.ts` and `tsconfig.json` if your template doesn't have it.

## Add components

<Terminal command={addCommand} output={react.add} planned />

## Import CSS and JavaScript

In `main.tsx`, import Bootstrap's CSS, then shadcn-bootstrap's files, then Bootstrap's JavaScript. Without server rendering it can load at the top level. It listens on `document`, so `data-bs-*` attributes work in everything React renders later.
